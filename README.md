# Maven Fuzzy Factory – SQL Analysis

## Project Overview

This project uses the Maven Fuzzy Factory e-commerce dataset to explore website activity and business data using MySQL.

The objective was to prepare the datasets for analysis, explore the database structure, and investigate website traffic patterns through SQL queries.

## Database & Tools

- **Database:** MySQL 8.0
- **SQL Environment:** MySQL Workbench
- **Supporting Tool:** Jupyter Notebook

## Dataset

The project includes the following datasets:

- Website Sessions
- Website Pageviews
- Orders
- Order Items
- Products
- Order Item Refunds
- Maven Data Dictionary

## SQL Work

The confirmed SQL work includes:

- Creating database tables with appropriate column data types.
- Importing CSV datasets into MySQL.
- Verifying imported records using row counts and sample queries.
- Exploring website sessions and marketing traffic sources.
- Grouping website sessions by UTM source and campaign.
- Comparing traffic volume across marketing sources and campaigns.

## Project Objective

To develop practical SQL experience by working with real-world e-commerce data and exploring how website traffic and marketing channels can be investigated through database queries.

## Dataset Source

Maven Analytics – Maven Fuzzy Factory dataset.
